# Source provenance

This package combines the project-specific camera experiment and installer with modified files and a host safety fixture from the pinned BluePilot/Panda/opendbc sources identified in README.md. Existing copyright/license notices inside those files are retained. Upstream licenses and any rights governing access to the BluePilot source continue to apply; this archive does not grant additional rights to upstream code or apply a new blanket license to it.

Manifest stock hashes identify the expected original inputs. Installed hashes identify the stationary payload. The package contains no compiled Panda firmware; the supported checkout supplies the pinned build tree and dependencies. checksums.json provides integrity values, not a cryptographic publisher attestation.
